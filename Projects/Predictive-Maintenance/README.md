# Predictive Maintenance System

Machine Learning project based on the AI4I 2020 Predictive Maintenance Dataset.

## Features
- Data preprocessing
- Machine failure prediction
- Streamlit web application
- Model deployment

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Joblib

## Files

- Predictive-Maintenance_model.pkl
