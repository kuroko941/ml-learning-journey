# Predictive Maintenance System

Machine Learning project to predict machine failure using the AI4I 2020 Predictive Maintenance Dataset.

## Features
- Data preprocessing
- Machine failure prediction
- Streamlit web application
- Random Forest / Gradient Boosting models

## Technologies
- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Joblib

## Dataset
AI4I 2020 Predictive Maintenance Dataset
